# StudentHub – Student Directory Portal

A responsive web application for exploring and filtering technical student profiles across MERN, MEAN, Python, Android, and iOS stacks.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)

### Running Locally
```bash
# Install dependencies
npm install

# Start the dev server
npm run dev
```

The portal runs on [http://localhost:5173](http://localhost:5173) and connects to the backend API at `http://localhost:3000`.
